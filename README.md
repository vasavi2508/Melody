# 🎵 Melody – Music Streaming Website

**Feel the Music, Live the Moment!**

Melody is a modern, responsive music streaming website designed to provide users with an enjoyable music discovery and listening experience. Users can explore popular artists, discover albums, browse playlists, listen to tracks, and manage their favourite songs through an interactive music player.

## 🌟 Features

### 🏠 1. Home Dashboard
- Modern and attractive landing page.
- Welcome banner with music-themed design.
- Quick access to different music sections.
- Dark theme with purple and neon-green accents.

### 🎤 2. Featured Artists
- Explore popular artists.
- View artist names, profile images, and music genres.
- Discover music from different artists.

### 💿 3. Popular Albums
- Attractive album cards with cover images.
- Album names and artist information.
- Release year details.
- Quick-play functionality.

### 🎧 4. Trending Playlists
Discover different playlists based on your mood:
- Top Hits 2026
- Romantic Melodies
- Relaxing Music
- Workout Beats
- Classical Vibes
- Trending Telugu Songs

### 🕒 5. Recently Played
- View recently played songs.
- Display song thumbnails and artist names.
- Show song duration.
- Quickly replay previous tracks.

### 🎶 6. Popular Tracks
- Browse available music tracks.
- View song titles, artists, albums, and durations.
- Play individual songs.
- Play All functionality.

### 🎼 7. Music Genres
Explore different music categories:
- Pop
- Rock
- Hip-Hop
- Classical
- Jazz
- Romantic
- Electronic
- Indian Music

### 🎛️ 8. Interactive Music Player
The fixed bottom music player includes:
- Play and Pause controls.
- Previous and Next track controls.
- Shuffle functionality.
- Repeat functionality.
- Music progress bar.
- Current playback time and total duration.
- Volume control.
- Current song and artist information.

### ❤️ 9. Favorites
- Add songs to favorites.
- Manage liked tracks.

### 🔍 10. Search and Navigation
- Search songs, artists, albums, and genres.
- Filter music based on search input.
- Smooth navigation between website sections.
- Mobile-friendly sidebar navigation.

## 🎨 Design Highlights

- Modern dark-themed interface.
- Purple and neon-green color combination.
- Attractive music cards and album artwork.
- Smooth hover animations and transitions.
- Responsive layouts for different screen sizes.
- Clean typography and user-friendly navigation.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/vasavi2508/Melody.git
```

2. Open the project folder:

```bash
cd Melody
```

3. Open `index.html` in your browser.

4. Explore the website and enjoy the music player features.

**Note:** An internet connection is required for external fonts, icons, images, Tailwind CSS CDN, and sample audio streams.

## 🎯 Project Objective

The main objective of Melody is to create an attractive and user-friendly music streaming interface that allows users to explore music, discover artists, browse playlists, and interact with music playback controls.

This project demonstrates practical knowledge of frontend web development, responsive design, HTML, CSS, and JavaScript.
